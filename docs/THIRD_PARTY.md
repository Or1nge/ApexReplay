# 第三方组件

- FFmpeg 8.1 LGPL shared 动态库，LGPL v3；许可文本在运行包 `licenses/FFmpeg.txt`。[项目源码](https://git.ffmpeg.org/ffmpeg.git)、[构建脚本](https://github.com/BtbN/FFmpeg-Builds)。使用动态库，未静态链接 FFmpeg。
- nlohmann/json 3.12.0，MIT；许可文本在 `docs/nlohmann-LICENSE.txt` 和运行包 `licenses/`。
- .NET 10 与 Windows Desktop Runtime，MIT；[源码及许可](https://github.com/dotnet/runtime)。自包含运行包中的微软运行时文件来自官方 SDK。
- Windows Graphics Capture、WASAPI、Windows OCR、D3D11 与 XInput 是 Windows 系统接口。NVENC 使用电脑已安装的 NVIDIA 驱动接口；程序不安装驱动。
